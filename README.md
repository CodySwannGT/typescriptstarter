# TypeScript Starter

This repository is a public Lisa starter seed for TypeScript projects.

It intentionally contains only the minimum PRD #692 seed:

- `package.json` with `@codyswann/lisa`
- Bun as the package manager
- `.gitignore`
- this README
- a follow-on `prd-ready` GitHub issue for the real runnable starter buildout

Use the follow-on PRD issue in this repository to build the full lint, test,
build, CI, and example source baseline.
